Abstract

This ontology models key concepts related to tourism information and recommendations, including hotels, tourist attractions, restaurants, events, and cities.

It enables semantic reasoning to identify the best-rated options in a given city using SWRL rules.

The ontology integrates terms from schema.org and aims to support intelligent systems that provide tourism-related suggestions based on user preferences and ratings.
